# 08 — AI Engineering

**Status:** 🟡 Reserved (no documents yet)

Home for documents specific to the **AI Engineering pipeline** — the eight-role chain
(Architecture → Database → UI/UX → Backend → Frontend → QA → DevOps, plus Solution
Architect) that runs after Product Owner approval (see
[05-AI-Product-Owner](../05-AI-Product-Owner/)) and produces the generated application (see
[02-Architecture](../02-Architecture/) for the generation engine's own architecture docs,
which this folder is not meant to duplicate).

This folder is meant for role-by-role documentation (responsibilities, prompt strategy,
context assembly, handoff contract to the next role) — currently these exist only as code
comments across `app/lib/projects/*Engine.ts` and `useAutoEngineeringPipeline.ts`. A
consolidated per-role reference is a good candidate for the first document here — see
[../DOCUMENTATION-ROADMAP.md](../DOCUMENTATION-ROADMAP.md).
