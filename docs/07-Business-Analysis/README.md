# 07 — Business Analysis

**Status:** 🟡 Reserved (no documents yet)

Home for documents specific to the **Business Analyst** AI role and the `RequirementsDraft`
synthesis step — the layer between Discovery (see
[06-Requirements-Discovery](../06-Requirements-Discovery/00-index.md)) and Product Planning
(see [05-AI-Product-Owner](../05-AI-Product-Owner/)).

This is distinct from Requirements Discovery: Discovery is about *gathering* business
understanding (Form, Interview, Document Upload, etc. — see the Builders Discovery
Experience master spec); Business Analysis is about *synthesizing* that understanding into a
structured `RequirementsDraft` a customer can approve.

Nothing lives here yet — `businessAnalystEngine.ts` and the `RequirementsDraft` schema are
currently documented only in code comments and in
[06-Requirements-Discovery](../06-Requirements-Discovery/00-index.md)'s design docs, which
reference this role but don't specify it directly. A dedicated specification for the Business
Analyst role itself (responsibilities, prompt strategy, `RequirementsDraft` schema, its own
decision points) is a good candidate for the first document here — see
[../DOCUMENTATION-ROADMAP.md](../DOCUMENTATION-ROADMAP.md).
