# 11 — Templates

**Status:** 🟢 Active

Reusable templates for authoring new Builders documentation. Every new document should start
from one of these rather than being written from a blank page — see
[../DOCUMENTATION-STANDARDS.md](../DOCUMENTATION-STANDARDS.md) for when to use which template.

| Template | Use for |
|---|---|
| [document-header.md](./document-header.md) | The standard header block every design/architecture/decision document should start with. |
| [design-doc-template.md](./design-doc-template.md) | A new architecture or product design specification (the kind of document Sprint 55/55.1/BDE are). |
| [adr-template.md](./adr-template.md) | A new entry in [09-Decisions](../09-Decisions/). |
